# Gestadia Portal y APP

Este repositorio contiene la web y el portal de clientes, la API y la APP React/Capacitor para iOS y Android.

**Para desarrollar pantallas o flujos, empieza por el [Manual de desarrollo APP](docs/app/MANUAL-DESARROLLO.md).** Es la entrada a los mapas, las imágenes, las decisiones vigentes y el procedimiento para mantenerlos. Se conserva en el repositorio junto al código; no depende de este chat ni de que siga abierto un servidor local.

| Necesitas | Referencia |
|---|---|
| Ver y seguir pantallas, flujo, Atrás y permisos | [Manual de desarrollo APP](docs/app/MANUAL-DESARROLLO.md) |
| Arrancar la APP, compilar o revisar su alcance | [README APP](README-APP.md) |
| Revisar el flujo propuesto con imágenes | [Mapas y capturas](docs/app/2026-10-10-mapas-pantallas-app-anonima.md) |
| Consultar API y responsabilidades entre sistemas | [Índice de integraciones](docs/integraciones/README.md) |
| Entender los nombres del proyecto | [Glosario](GLOSARIO.md) |
| Consultar entregas y antecedentes | [Handoff técnico](HANDOFF.md) |

La navegación implementada y la propuesta de LidIA sin cuenta están separadas en los mapas. El recorrido anónimo tiene conformidad documental LidIA, pero conserva pendientes la aprobación humana y los contratos técnicos. Integrar sus documentos no activa esa funcionalidad.
